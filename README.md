# Portfolio UX/UI (Next.js)

Este proyecto está preparado para correr con **Next.js + Tailwind + Framer Motion** y replicar el estilo/animaciones del video (cards flotantes, parallax, scroll-trigger y microinteracciones).

## Requisitos
- Node.js 20+ (ideal 22)

## Instalar y correr
> Nota: en este entorno no hay acceso a internet, así que la instalación de dependencias debes hacerla en tu PC.

```bash
cd portfolio-ux
npm install
npm run dev
```

Abrir: http://localhost:3000

## Editar contenido
Los proyectos se editan en:
- `src/content/projects.ts`

## Deploy
Funciona bien en Vercel o Netlify (build `npm run build`).
